About Bob CodeGuard

🔍

Stage 1 — Bug Fix

Analyzes GitHub issues, traces root causes through source code, proposes evidence-based fixes, and generates regression tests.

🔬

Stage 2 — PR Review

Runs four specialized agents in parallel: Security, Code Quality, Testing, and Regression. Every finding is grounded in real evidence.

🕵️

Stage 3 — PR Detective

Traces the ripple effect of every change — direct deps, indirect deps, callers, APIs, DB, tests, and docs far beyond the diff.

📖

Stage 4 — Doc Sync

Compares source code against all documentation and detects drift: outdated API examples, wrong parameters, missing entries.
